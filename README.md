# Diario KB

App web instalable (PWA) para seguir programas mensuales de kettlebell.

- **Meses importables**: cada mes es un archivo JSON (formato `is-month-v1`) que se importa desde el móvil y se guarda solo en el navegador. La app no incluye ningún programa.
- **Semana en curso** calculada desde el día en que empiezas el mes, con el orden de sesiones de cada semana.
- **Sesiones guiadas** por bloques: P3/preparación, circuito con tiempo límite y contador de rondas, series con descanso automático, series por tiempo (trabajo/descanso) y bloques cada X segundos.
- **Pesos** que se recuerdan por ejercicio, saltando entre las kettlebells que tienes.
- **Historial continuo** entre meses, gráfica de peso por ejercicio, copia de seguridad en JSON y exportación a CSV.

Los datos (meses y sesiones) viven solo en el móvil; este repositorio no contiene datos personales ni programas.

## Instalar en Android
1. Abrir la dirección de GitHub Pages en **Chrome**.
2. Menú ⋮ → **Instalar aplicación**.
3. Funciona sin conexión.
